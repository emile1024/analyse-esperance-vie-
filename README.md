# Analyse de l'espérance de vie

## Contexte

Ce projet est réalisé dans le cadre du cours Projet Analyse de données.
Il vise à appliquer une démarche complète d'analyse de données selon
CRISP-DM, avec une organisation du travail basée sur Scrum.

## Problématique

Quels facteurs sanitaires et socio-économiques sont associés à
l'espérance de vie dans les pays étudiés entre 2000 et 2015 ?

## Objectif général

Analyser les relations entre l'espérance de vie et différents
indicateurs sanitaires et socio-économiques afin d'identifier les
facteurs les plus fortement associés aux différences observées.

## Méthodologie

Le projet suivra les principales étapes de CRISP-DM :

1. Compréhension métier
2. Compréhension des données
3. Préparation des données
4. Analyse exploratoire
5. Évaluation et interprétation
6. Communication des résultats

## Outils

- Python
- Jupyter Notebook
- Git / GitHub
- Jira / Scrum
